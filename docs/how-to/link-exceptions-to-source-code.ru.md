# Как связать трассировки стека исключений с исходным кодом

На странице **Exceptions** откройте группу, чтобы увидеть примеры её
вхождений. Когда для сервиса настроен репозиторий исходников, путь к файлу в
каждом кадре стека становится ссылкой на этот файл и строку в вашем
репозитории на коммите, из которого собран сервис.

## Предварительные требования

- Трассировки стека с путями к файлам. .NET выводит `in /src/File.cs:line 42`,
  если сборка содержит portable PDB (так по умолчанию).
- Вы администратор или аутентификация отключена. Наблюдатели и участники видят
  ссылки, но не могут менять настройки.

## Пометьте сборку коммитом

Flare берёт коммит из атрибутов ресурса спана в таком порядке:

1. `vcs.ref.head.revision`
2. `vcs.revision`
3. `service.version`

Для .NET проще всего SourceLink: он добавляет коммит в информационную версию
(`1.2.3+abc1234`), и Flare читает часть после `+`. Если `service.version` —
просто `1.2.3`, коммит из неё не определить, и Flare использует ветку или тег
по умолчанию, указанные ниже.

## Настройте репозиторий

1. В строке вхождения нажмите значок ссылки рядом с **Show stack trace**.
2. Выберите хостинг: GitHub, GitLab или Azure DevOps.
3. Укажите URL репозитория, например `https://github.com/acme/shop`. Для
   Azure DevOps — `https://dev.azure.com/org/project/_git/repo`.
4. При необходимости задайте запасную ветку или тег, например `main`.
5. Задайте **префикс пути**, если путь сборки не относителен репозиторию. Это
   каталог, в котором шла сборка; Flare отбрасывает его из каждого кадра.
   Например, `/src/` при сборке в Docker или `/home/runner/work/shop/shop/` в
   GitHub Actions.
6. Нажмите **Save**.

Сборки с `<Deterministic>` и `ContinuousIntegrationBuild` уже переписывают пути
так, что они начинаются с `/_/`; Flare отбрасывает этот префикс без настройки.

## Когда кадр не становится ссылкой

Flare оставляет кадр обычным текстом, а не гадает:

- путь абсолютный и не начинается с заданного префикса;
- вместо пути только имя файла без каталога, как в кадрах Java;
- у вхождения нет коммита, а у сервиса нет запасной ветки.
