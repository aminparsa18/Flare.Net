# Как сравнить два деплоя сервиса

Flare сравнивает две версии сервиса, чтобы на одном экране ответить на вопрос «сломал ли что-нибудь мой деплой?». Кроме версии у сервиса, дополнительная инструментация не нужна.

## Задайте версию

Задайте атрибут ресурса `service.version`. В .NET с OpenTelemetry:

```csharp
builder.Services.AddOpenTelemetry()
    .ConfigureResource(resource => resource.AddService("orders-api", serviceVersion: "2.4.0"));
```

Подойдёт любая строка (семантическая версия, номер сборки, хеш коммита). Версии читаются из спанов и логов, поэтому новый деплой появляется, как только начинает слать телеметрию.

## Сравните

1. Откройте **Traces**, затем вкладку **Services**.
2. Откройте сервис (нажмите на его узел в представлении **Map**).
3. Раздел **Сравнение деплоев** находится под результатами проверки среды выполнения. По умолчанию сравниваются новейшая версия и версия, впервые замеченная перед ней. Другую пару можно выбрать двумя переключателями.

Сравнение смотрит на 7 суток назад. Если за это время сервис прислал только одну версию или ни у чего нет `service.version`, раздел сообщит об этом.

| Часть | Что показывает |
| --- | --- |
| Эндпоинты | Серверные и consumer-спаны по имени: число вызовов, доля ошибок и задержка p95 в каждой версии. **Хуже** отмечает рост доли ошибок на процентный пункт и больше либо рост p95 на четверть и не менее чем на 20 мс. **Новый** и **Пропал** отмечают эндпоинты, которые обслуживала только одна версия |
| Новые типы исключений | Типы исключений, встреченные в текущей версии и ни разу не встречавшиеся в базовой |
| Новые исходящие зависимости | Внешние хосты и СУБД, вызванные в текущей версии и ни разу не вызванные в базовой |
| Новые шаблоны логов | Шаблоны логов Drain, встреченные в текущей версии и ни разу не встречавшиеся в базовой |

Эндпоинты, типы исключений и ссылка **Логи этой версии** открывают соответствующий обозреватель для этого сервиса и версии за окно, в котором видна текущая версия.

## Ограничения

- «Впервые замечена» считается внутри 7-суточного окна, поэтому если базовая версия перестала слать данные до его начала, всё выглядит новым.
- Телеметрия без `service.version` не сравнивается.
- Результат считается по вашим данным при открытии раздела. API за ним: `POST /api/services/version-comparison`.
