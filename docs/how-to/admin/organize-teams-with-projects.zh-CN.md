# 使用项目组织团队

默认情况下，每个已登录用户都能看到所有服务、仪表板、告警和采集密钥。**项目**为团队划定边界：一组命名的服务，以及有权查看它们的成员。使用项目需要启用身份验证（参见[配置身份验证](configure-authentication.zh-CN.md)）。

## 创建项目

1. 以全局 Admin 身份登录，打开 **Settings > Projects**，然后点击 **New project**。
2. 填写名称，并列出项目拥有的服务，每行一个 `service.name`。末尾的 `*` 表示前缀匹配（`checkout-*`）。单独的 `*` 会被拒绝，避免项目悄悄拥有一切。
3. 打开 **Members**，添加用户并指定项目角色：**Admin**、**Member** 或 **Viewer**。

不同项目的匹配模式可以重叠；用户看到的是其所属项目的并集。

## 项目限定的范围

只要存在至少一个项目，非管理员用户在日志、链路、指标、错误、仪表板面板、SLO 和实时尾随中只能看到其项目允许的服务。不匹配任何项目的服务只有全局 Admin 可见。不属于任何项目的非管理员什么也看不到。全局 Admin 始终可以看到全部。收窄项目的匹配模式会立即生效。

不受限定的内容：不按服务划分的基础设施页面（Hosts、Kubernetes、采集健康状况），以及 broker 级别的积压指标（Kafka lag、队列深度）。

## 为仪表板、告警、SLO、视图和采集密钥指定项目

仪表板、告警规则、SLO 和已保存视图的创建表单都有 **Project** 选择器，**Settings > Ingest keys** 下的 **New key** 也有。属于某个项目的对象只有该项目成员和全局 Admin 可见。没有项目的对象与以前一样对整个实例可见。之后要移动采集密钥，请使用其所在行的文件夹按钮。

写入项目所有的对象需要项目角色 Admin 或 Member。项目角色只能收窄全局角色：全局 Viewer 即使是项目 Member 也无法编辑。项目 Admin 可以修改项目内的任何仪表板。

采集密钥的管理仍仅限全局 Admin，因为密钥可以以任意 `service.name` 采集数据。

## 切换项目

当你属于某个项目后，顶部栏会出现项目切换器。选择项目会将仪表板、告警、SLO 和已保存视图过滤到该项目（全实例对象始终显示），并将其设为新对象的默认项目。它不会改变你能查询的遥测数据，那始终取决于你的成员身份。

删除项目会使其对象对除全局 Admin 以外的所有人隐藏，直到有人重新分配它们。
