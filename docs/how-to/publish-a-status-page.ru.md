# Как опубликовать страницу статуса

**Страница статуса** — это страница только для чтения с состоянием сервисов, которую может открыть любой, у кого есть ссылка, без учётной записи Flare. Она показывает текущее состояние каждого компонента и ежедневную доступность за последние 90 дней. Компонент — это [синтетический монитор](synthetic-monitoring.ru.md) или [SLO](define-slos.ru.md), и страница показывает только заданное вами имя.

## Создайте страницу

Откройте **Settings > Workspace > Status pages** (Admin) и выберите **New status page**:

1. Задайте **название** и **слаг в URL** (строчные буквы, цифры и дефисы). Страница доступна по адресу `/status/<слаг>` на дашборде.
2. Добавьте **компоненты**: выберите мониторы и SLO и измените публичное имя каждого. Цели мониторов и имена SLO никогда не показываются.
3. Включите **Published**. Страницы создаются неопубликованными, а неопубликованная страница отвечает 404.

То же можно сделать через API (`/api/status-pages`, Admin) с сессионным cookie или персональным токеном доступа:

```bash
curl -X POST "$FLARE_API/api/status-pages" \
  -H "Authorization: Bearer $FLARE_PAT" -H "Content-Type: application/json" \
  -d '{"slug":"status","title":"Acme status","enabled":true,
       "components":[{"name":"Website","kind":"Monitor","refId":"<monitor id>"},
                     {"name":"Checkout API","kind":"Slo","refId":"<slo id>"}]}'
```

`GET`, `PUT` и `DELETE` на `/api/status-pages/{id}` читают, меняют и удаляют страницу.

## Что видят посетители

| Состояние | Компонент-монитор | Компонент-SLO |
| --- | --- | --- |
| Operational | Все недавно отвечавшие локации видят его доступным. | Бюджет ошибок не израсходован. |
| Degraded | Часть локаций видит его недоступным. | Бюджет ошибок превышен. |
| Outage | Все локации видят его недоступным. | |
| No data | Отключён, ни разу не проверялся или нет результатов за три интервала. | Нет трафика в окне SLO. |

Баннер вверху показывает худшее состояние среди компонентов. У каждого компонента также есть полоса до 90 дней, по одному сегменту на день UTC: зелёный при 99,9% и выше, жёлтый при 95% и выше, красный ниже. День монитора — доля успешных проверок. День SLO — доля хороших событий, и SLO показывает не больше дней, чем его окно.

## Что важно знать

- Страница публична для всех, кто имеет доступ к экземпляру. Снимите публикацию или удалите страницу, чтобы ссылка перестала работать сразу.
- Результат кешируется на 30 секунд, поэтому изменение может появиться с такой задержкой. Страница сама обновляется раз в минуту.
- Переименование монитора начинает его историю заново, потому что результаты проверок хранятся под именем монитора.
- Компонент, чей монитор или SLO удалён, остаётся на странице как **No data**; уберите его в редакторе.
