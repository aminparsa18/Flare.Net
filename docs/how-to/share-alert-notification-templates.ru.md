# Как использовать общие формулировки уведомлений в правилах оповещений

Шаблон уведомления — это именованные заголовок и текст, которые могут
использовать многие правила. Измените шаблон один раз, и все правила, которые
его используют, начнут отправлять новый текст.

## Создание шаблона

Откройте **Настройки > Шаблоны уведомлений** и нажмите **Новый шаблон**.
Заполните:

- **Заголовок** и **Текст (срабатывание)** с тем же синтаксисом
  `{{placeholder}}`, что и в собственном сообщении правила (например,
  `[{{status}}] {{rule_name}}`). Неизвестные плейсхолдеры отклоняются при
  сохранении.
- **Текст (восстановление)** — необязательно. Используется в уведомлениях о
  восстановлении. Если пусто, берётся текст срабатывания.
- **Тексты для отдельных каналов** — необязательно. Заменяют текст срабатывания
  для одного типа канала, например короткий для Telegram и длинный для Email.

## Использование в правиле

В форме правила выберите шаблон в поле **Шаблон уведомления**. Список
появляется, когда существует хотя бы один шаблон. Текст, написанный в разделе
«Настроить текст уведомления», по-прежнему переопределяет шаблон — отдельно для
каждого поля.

## Шаблон по умолчанию

Включите **Использовать как шаблон по умолчанию** для одного шаблона. Он
применяется ко всем правилам без выбранного шаблона. Шаблоном по умолчанию
может быть только один. Без шаблона по умолчанию и без выбранного шаблона
правила используют встроенные формулировки каналов.

## Удаление шаблона

Шаблон, который ещё используют правила, удалить нельзя. В сообщении об ошибке
перечислены эти правила; сначала выберите в них другой шаблон.

## Экспорт и импорт

`flare alerts export` записывает шаблон правила по названию, а `import` ищет это
название на целевом экземпляре. Сначала создайте там шаблон, иначе правило
будет показано как ошибка.

API — `/api/alert-templates`. Устройство описано в
[ADR-0148](../../docs-internal/adr/0148-shared-alert-notification-templates.md).
